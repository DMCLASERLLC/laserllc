JOE CARROLL PORTFOLIO WEBSITE

Files:
- index.html: complete responsive website
- assets/: project photos used in the gallery

To preview:
1. Extract the ZIP.
2. Open index.html in a web browser.

Before publishing:
1. Open index.html in a text editor.
2. Find YOUR-EMAIL@example.com and replace it with Joe's real business email.
3. Add a real phone number / business contact details if desired.
4. Upload the entire folder (index.html plus assets folder) to a web host.

The contact form uses a mailto link. It opens the visitor's email app and does not submit to a server.
The engineering drawing PDFs were not included in the public website package.
